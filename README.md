# Игры

Две игры на чистом HTML5, без установки. Открой файл в браузере.

## Сектор Ноль (`fps.html`)

Шутер от первого лица на three.js. В руках шесть предметов: энергоклинок, пистолет, дробовик, плазменная винтовка, граната и стимулятор. Волны гончих, дронов и громил, босс каждую пятую волну.

Управление: `WASD` ход, `Shift` бег, мышь обзор и огонь, `Пробел` прыжок, `R` перезарядка, `1–6` или колесо — предмет в руках, `ПКМ` удар клинком, `G` граната, `F` стимулятор, `Esc` пауза.

Рядом с `fps.html` должен лежать `three.min.js` (three.js r128, лицензия MIT).

## Неоновый Разлом (`index.html`)

Аркадный top-down шутер на Canvas: волны врагов, боссы, три оружия, 14 усилений.

Управление: `WASD` ход, мышь прицел и огонь, `Пробел` рывок, `1 2 3` / `Q` оружие, `Esc` пауза, `M` звук.

## Windows

Готовые файлы: `dist/SectorZero.exe` и `dist/NeonRift.exe`. Игра встроена внутрь, установка не нужна. Окно работает через WebView2, который есть в Windows 10 и 11; если его нет, игра откроется в браузере.

Сборка из исходников (нужен Go, собирается с любой ОС): `./build.sh`
