# Игры

Две игры для Windows без установки: готовые exe лежат в `dist/`. Исходники каждой игры — один HTML-файл, который встроен в exe.

## Сектор Ноль (`fps.html`)

Шутер от первого лица на three.js: бетонный склад, робопсы, квадрокоптеры, самоходные мины, шагоходы, штурмовой вертолёт и танк.

- **Лобби:** вкладки «Играть», «Инвентарь», «Магазин»; прогресс сохраняется локально.
- **Карты:** Склад, Ангар, Коридоры; на каждой стоят взрывающиеся бочки.
- **Настройки:** чувствительность мыши, громкость, угол обзора, качество графики, полный экран; там же статистика.
- **Режимы:** Выживание, Штурм (10 волн), Орда (3 минуты), Полигон (тренировка). Три уровня сложности.
- **Оружие:** нож, пистолет, револьвер, пистолет-пулемёт, дробовик, автомат, снайперская винтовка, пулемёт, граната, шприц-тюбик.
- **Прицелы:** мушка, коллиматор, голограф, оптика 4×; у снайперской винтовки встроенная 6×.
- **Усиления:** после каждой отбитой волны выбираешь одно из трёх, действует до конца вылазки.
- **Прогресс:** контракты с наградой, звания, улучшения урона и магазина для каждого ствола.
- **Скины:** окраски оружия и перчатки за кредиты, которые зарабатываются в бою. Покупок за реальные деньги нет.

Управление: `WASD` ход, `Shift` бег, `ЛКМ` огонь, `ПКМ` прицел, `R` перезарядка, `1–6` или колесо — слоты, `V` нож, `G` граната, `F` шприц-тюбик, `Пробел` прыжок, `C` присесть, на бегу — подкат (`X` — зафиксировать), `Esc` пауза.

Рядом с `fps.html` должен лежать `three.min.js` (three.js r128, лицензия MIT).

## Неоновый Разлом (`index.html`)

Аркадный top-down шутер на Canvas: волны врагов, боссы, три оружия, 14 усилений.

Управление: `WASD` ход, мышь прицел и огонь, `Пробел` рывок, `1 2 3` / `Q` оружие, `Esc` пауза, `M` звук.

## Windows

Готовые файлы: `dist/SectorZero.exe` и `dist/NeonRift.exe`. Игра встроена внутрь, установка не нужна. Окно работает через WebView2, который есть в Windows 10 и 11; если его нет, игра откроется в браузере.

Сборка из исходников (нужен Go, собирается с любой ОС): `./build.sh`
