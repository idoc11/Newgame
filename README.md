# Неоновый Разлом

Аркадный top-down шутер на чистом HTML5 Canvas, без зависимостей. Открой `index.html` в браузере.

- Волны врагов семи типов, босс каждую пятую волну
- Три оружия: бластер, дробовик, рельса
- 14 усилений на выбор между волнами
- Рывок с неуязвимостью, комбо-множитель, рекорд сохраняется локально

Управление: `WASD` ход, мышь прицел и огонь, `Пробел` рывок, `1 2 3` / `Q` оружие, `Esc` пауза, `M` звук. На телефоне два стика.

## Windows

Готовый файл: `dist/NeonRift.exe`. Игра встроена внутрь, установка не нужна. Окно работает через WebView2, который есть в Windows 10 и 11; если его нет, игра откроется в браузере.

Сборка из исходников (нужен Go, собирается с любой ОС):

```
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H windowsgui -s -w" -o dist/NeonRift.exe .
```
